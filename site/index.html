05 / COMMON QUESTIONS

Before you
hit run.

Is this a live price-comparison website?+

No. This is a project overview. The repository contains a standalone best-effort URL checker, a mock-data AI agent and a local SQLite dashboard; they are not yet a unified live shopping product.

Does the catalog already contain a million products?+

No. The importer targets up to one million accepted source rows. You must download and import the Open Food Facts export yourself, and the unique imported count may be lower. Data mainly covers food and grocery items.

Why is the database separate from the AI agent?+

The project is evolving in phases. The Groq/OpenAI ReAct agent currently uses a fictional USD catalog, while the SQLite backend stores validated INR observations. Connecting these responsibly is future work.

Why does the demo raise a duplicate observation error?+

The demo reuses a source record identifier with a new timestamp on later runs. The database refuses the conflicting duplicate to protect append-only history. Run the demo once per new database file, then launch only the dashboard.
